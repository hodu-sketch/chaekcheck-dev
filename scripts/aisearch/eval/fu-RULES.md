# 이어 묻는 질문 만들기

도서관 앱 「AI 책 찾기」에서 사람이 첫 질문(`q1`)을 쳤고, 앱이 책 8권(`shown`, 차례대로 1\~8번)을 보여 줬다. 그다음 사람이 칠 법한 **두 번째 질문**을 쓴다.

1. 이 폴더의 `in-N.jsonl`(맡긴 사람이 N을 알려 줌)을 Read로 읽는다. 한 줄 = `{"id", "q1", "shown": ["제목 / 저자", …]}`.
2. 줄마다 두 번째 질문 3개를 쓴다. 종류마다 하나씩:
   - `refers` (앞에 보인 책 안에서 다시 고르기): 보인 책을 순서·조건·비교로 가리킴. 예: 「이 중에 소설만」, 「두 번째 거랑 비슷한 거」, 「3번은 어려워?」, 「여기서 제일 얇은 거」, 「그 작가 책 더」.
   - `modify` (앞 질문의 주제는 그대로, 조건만 바꿔 새로 찾기): 주제 낱말 없이 조건만. 예: 「더 쉬운 걸로」, 「이번엔 청소년용으로」, 「소설 말고」, 「한국 작가 걸로」, 「그림 많은 거」, 「요즘 나온 걸로」.
   - `shift` (앞 질문 주제를 좁히거나 옆으로 옮겨 새로 찾기, 또는 같은 주제로 더): 예: 「그중에 식단 말고 운동 쪽은?」, 「비슷한데 직장인 얘기로」, 「다른 것도 더 보여줘」.
   - 말투(반말·존댓말·짧은 말·오타)를 섞고 5\~40자. q1의 내용과 보인 책에 맞게, 실제 사람처럼 쓴다. 스크립트로 찍어 내지 말고 하나씩 직접.
3. 질문마다 `want`에 「이제 사람이 원하는 책」을 한 문장으로 적는다(채점용, 앞 대화의 뜻을 합쳐서). 예: q1 「다이어트 식단을 자세히 다룬 책」 + 「더 쉬운 걸로」 → 「다이어트 식단을 다룬, 처음 보는 사람도 읽기 쉬운 책」. `refers`는 「보인 책 중 소설인 것」처럼.
4. 결과를 Write 한 번으로 이 폴더의 `fu-N.jsonl`에 쓴다: 질문마다 한 줄 `{"id": "<원래 id>-<refers|modify|shift>", "base": <원래 id>, "kind": "…", "q2": "…", "want": "…"}`, 입력 차례대로, 다른 글 없이.
5. 다른 파일은 읽거나 쓰지 않고 명령도 돌리지 않는다. 답은 `done <쓴 줄 수>`만.
