# 책 프로필 만들기 (AI 책 찾기용)

1. 맡은 입력 파일 `in-NNN.tsv`를 Read 도구로 25줄씩 나눠 읽는다(offset 1, 26, 51, 76, 101, 126, limit 25). 한 줄 = book_id<TAB>제목<TAB>저자<TAB>KDC<TAB>대상(국가서지)<TAB>소개(앞 600자).
   - KDC·대상은 국립중앙도서관 국가서지 값이고 비어 있을 수 있다. 참고만 하고, 소개와 다르면 소개를 따른다.
2. **모든** 책마다 아래 JSON 한 개를 만든다. 소개·제목·저자·KDC에서 알 수 있는 것만 쓰고 지어내지 않는다.
   - `fiction`: 소설·시·희곡·동화·만화처럼 지어낸 이야기이면 true, 아니면 false
   - `category`: 아래 중 하나 — 소설, 시·희곡, 에세이, 인문·철학, 역사, 사회·정치, 경제·경영, 자기계발, 심리, 과학, 기술·IT, 건강·의학, 요리·생활, 육아·교육, 예술·취미, 여행, 종교, 어린이, 청소년, 만화, 외국어, 기타
   - `audience`: 아동 | 청소년 | 일반 | 전문
   - `level`: 입문 | 교양 | 전문 (알 수 없으면 교양)
   - `topics`: 1~5개, 책이 다루는 주제를 사람들이 찾을 때 쓸 한국어 낱말(예: "번아웃", "행동경제학", "조선 후기", "성장 소설", "1인 가구 요리")
   - `mood`: 0~2개(예: "따뜻함", "유쾌함", "긴장감", "위로", "진지함"), 모르면 빈 배열
   - 소개에 내용이 없으면(제목·권차뿐 등) 제목·저자·KDC만으로 `category`·`fiction`·`audience`를 정하고 `topics`는 빈 배열
3. 결과를 Write 한 번으로 같은 폴더의 `out-NNN.jsonl`(입력과 같은 번호)에 쓴다: 책마다 한 줄 `{"id": book_id, "fiction": …, "category": …, "audience": …, "level": …, "topics": […], "mood": […]}`, 입력 차례 그대로, 다른 글 없이.
4. 다른 파일은 읽거나 쓰지 않고, 명령도 돌리지 않는다. 답은 `done <쓴 줄 수>`만.
