# 「책 찾기 아님」 질문 중 「책첵 질문」 고르기

1. 이 폴더의 `SITE_INFO.md`(책첵 사이트 정보)를 Read로 읽는다.
2. 맡은 파일들(맡긴 사람이 알려 줌)을 Read로 읽는다. 한 줄 = `{"id", "type": "not_book", "q"}`. 모두 「책을 찾는 말이 아님」으로 만든 글이다.
3. 그중 **사이트 정보가 답할 수 있는 질문**을 고른다: 책첵 자체(뭐 하는 곳, 무료, 가입, 정보 출처, 메뉴·기능, 문의) 또는 전자도서관 이용 일반(가입 조건, 다른 지역 도서관, 대출·연장·반납을 어디서 하는지, 대출 가능인데 안 빌려질 때). 특정 도서관의 운영 시간·위치처럼 사이트 정보에 없는 것, 인사·잡담·감정·다른 서비스 요청은 고르지 않는다.
4. Write 한 번으로 이 폴더의 `relabel-<이름>.json`(이름은 맡긴 사람이 알려 줌)에 고른 글의 id 배열만 쓴다: `["id", …]`. 다른 글 없이.
5. 다른 파일은 읽거나 쓰지 않고 명령도 돌리지 않는다. 답은 `done <고른 수>`만.
