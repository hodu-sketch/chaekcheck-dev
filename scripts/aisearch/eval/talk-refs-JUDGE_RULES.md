# AI 검색 대화 채점 (대화를 가리키는 말)

1. `C:\Users\yujun\Documents\Claude\Projects\chaekcheck-dev\data\aisearch-eval-2026-10-25\talk-refs\jd\in-NN.json`(맡긴 사람이 NN을 알려 줌)을 Read로 읽는다. 배열 한 항목 = `{"key", "talk", "question", "answer", "want", "check"}`.
   - `talk`: 앞 대화(사용자 말과 앱의 답). `question`: 지금 사용자 말. `answer`: 앱의 지금 답(되물음과 고를 답, 또는 머리말과 카드 목록).
   - `want`: 사용자가 실제로 원한 것(앱은 몰랐다). `check`: 이 턴에서 특히 볼 것.
2. 항목마다 두 가지를 정한다.
   - `pass`(true/false): 이 답이 `want`와 `check`에 맞게 대화를 이어 갔나. 되물었다면 고를 답이 대화에 나온 주제에서 나왔는지, 대화와 상관없는 고정 예시(「처음 읽는 경제 교양서」 같은)인지 본다. 카드를 보였다면 원한 주제인지, 말하기·대화법 책처럼 「그거 말고」의 낱말에 끌려간 엉뚱한 책은 아닌지, 「목록」 같은 말을 쓰지 않았는지 본다. `check`가 비어 있으면 `want`만 본다.
   - `cards`: 카드가 있으면 카드마다 `want`에 맞는 정도 0~3(3 딱 맞음, 2 대체로 맞음, 1 주제만 조금 닿음, 0 맞지 않음)을 카드 순서대로. 카드가 없으면 빈 배열.
   - 책 정보는 제목·저자·카드 글만 보고 판단한다.
3. Write 한 번으로 같은 폴더의 `out-NN.json`에 `{"<key>": {"pass": true, "cards": [3, 2], "why": "한 줄 까닭"}, …}`로 쓴다. 다른 글 없이.
4. 다른 파일은 읽거나 쓰지 않고 명령도 돌리지 않는다. 답은 `done <항목 수>`만.
