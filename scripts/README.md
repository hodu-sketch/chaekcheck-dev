# scripts — 서비스 밖에서 손으로 돌리는 도구

서버·웹 코드와 달리, 여기 있는 것은 PC에서 손으로 돌리는 도구입니다. 빌드·CI에 들어가지 않습니다. 대부분 Python 3.11 이상이고, 몇 개는 PowerShell·`.cmd`·셸 스크립트입니다. `library/`의 `*.java`는 JDK 25로 바로 실행하는 단일 파일입니다(실행법은 각 파일 머리말).

- **데이터는 저장소 밖에 있습니다.** 수집한 책 목록, 모델, 실험 결과는 이 저장소 옆 폴더 `chaekcheck-data`(또는 환경 변수 `CHAEKCHECK_DATA`)와 git에 넣지 않는 `data/`에 둡니다. 스크립트는 자기 위치를 기준으로 그 폴더를 찾습니다.
- **스크립트마다 맨 위 설명**에 무엇을 하는지, 어떻게 돌리는지, 근거 문서가 적혀 있습니다. 아래 표의 「하는 일」은 그 설명의 첫 문장입니다.
- **폴더마다 README**가 있고, 그 안에 스크립트 전체 목록(파일 · 하는 일 · 설명 문서)이 있습니다. 목록은 `python scripts/index_scripts.py`로 다시 만듭니다. 스크립트를 더하거나 이름을 바꾸면 이 명령을 다시 돌립니다.
