## 1. 지금 화면 (최종 상태)

### 1-1. 머리말·바닥글·탭 제목

- 브라우저 탭 제목: **"책첵"** (전에는 "책첵 · 전자도서관 대출 가능 여부").
- 머리말 한 줄 소개: "전자도서관 대출 가능 확인" (폰에서는 숨김, 전과 같음).
- 바닥글: 폰에서만 한 단계 작은 글자(`--text-xs`)와 좁은 여백.

### 1-2. 검색 화면 S1, PC·태블릿

사진: `pc-first-screen.png`, `pc-results-before-login.png`, `pc-results-after-login-my-library-open.png`

- 검색칸 아래 한 줄에 세 컨트롤을 **연회색 박스**(`--tray` #eceff3)로 묶음: [전체 도서관 | 내 도서관] 스위치(흰 바탕, 고른 쪽 연보라), [방문 없이 가입], **[내 도서관 관리 ▾]**(로그인 뒤) 또는 **[내 지역 ▾]**(로그인 전). 셋 다 같은 높이(`--control-height`).
  - 이 모양은 사용자가 시안 5개(지금 / 토스증권 칩 / 머티리얼 3 / 애플 iOS / 보라 톤)를 본 뒤 "지금이 가장 나은거 같아 냅둬"로 확정.
- **검색칸 아래 "내 도서관 · 거주 … · 직장 … · 직접 추가 N곳 · 관리" 줄과 로그인 전 "내 지역 · 거주 … · 변경" 줄은 없어짐.** 그 내용은 위 버튼을 누르면 열리는 작은 창(제목, 거주·직장·직접 추가 줄, [관리] → S10 또는 [변경] → S2)에 있음. 로그인 전에 지역이 없으면 버튼이 "내 지역 설정"이고 누르면 S2가 바로 열림.
- **검색 결과가 있는 화면은 가운데 한 칸, 최대 46rem(약 900px, `--content-width`)**. 구글 검색 결과(결과 칸 652px 고정)를 재서 우리 글자 크기(약 1.33배)에 맞춘 값. 시안 A(구글처럼 왼쪽)·B(가운데) 중 B. 책 화면 S3도 같은 폭. 첫 화면·S6·S8·S9·S10은 그대로.

### 1-3. 검색 화면 S1, 폰

사진: `phone-first-screen.png`, `phone-results.png`, `phone-settings-with-scope.png`

- 검색줄 두 줄: 첫 줄 검색칸(폭 전체, "검색" 글자, 자리 글 "책 제목을 입력하세요"), 둘째 줄 **[여러 조건 ▾](글자, 글자 폭)** + 설정 버튼 + (결과가 있을 때) **[기본 순서 ▾] 오른쪽 끝**. 첫 화면에서는 둘째 줄이 가운데.
- **검색칸 아래 세 컨트롤 박스를 그리지 않음 (D안).** 설정 버튼(조절 막대 아이콘)을 누르면 열리는 창 맨 위에 **"찾을 도서관"**: [전체 도서관 | 내 도서관](폭 전체), [방문 없이 가입], [내 도서관 관리](S10으로 가는 링크) 또는 [내 지역 설정]/[내 지역 변경](S2). 그 아래는 전과 같은 "보기 방식", "도서관에서 직접 찾기", "계정".
  - 기본값과 다르면 설정 버튼 오른쪽 위에 보라 점. 기본값 = 로그인 뒤 내 도서관이 있으면 "내 도서관", 아니면 "전체 도서관" / "방문 없이 가입" 끔. 읽는 이름 "검색 설정 (찾을 도서관 바꿈)".
  - 사용자가 시안 4개(검색줄에 버튼 하나 더 / 요약 칩 / 한 줄 글 펼침 / 설정 창에 합치기)를 보고 D안을 고름.
- 결과 목록: 회색 바탕 위 **흰 카드**(바깥 흰 판 없음). 결과 판 위의 정렬 자리는 폰에서 숨김(정렬은 검색줄로 옮김).

### 1-4. 결과 카드 (바로 보기, 책 화면 S3)

사진: `pc-results-before-login.png`, `phone-results.png`, `pc-book-page.png`

- **카드 전체가 그 도서관의 책 페이지 링크(새 창).** "도서관에서 보기" 버튼은 없어짐. 도서관 이름(가입 정보 창)과 "구독형 · 바로 대출 ⓘ"(예산 안내 창)은 카드 위에 떠서 눌러도 넘어가지 않음. 주소가 없는 줄은 링크가 아님. 링크의 읽는 이름 "{도서관 이름}에서 보기 (새 창)".
- 상태 칸
  - **없앤 것: "지금 대출 가능"(N권 포함), "예약 대기 N명"**. 묶음 제목("지금 빌릴 수 있어요", "예약하고 기다려요")과 보유·대출 중·예약 칸이 같은 뜻이라서.
  - 남은 것: "구독형 · 바로 대출 ⓘ", 보유 수가 없는 곳의 "대출 중 · 예약", "확인 실패", "대출 정보 조회 중", "대출 가능 여부 확인 필요".
- **보유·대출 중·예약은 칸으로 감쌈**(모든 폭). "구독형 · 바로 대출 ⓘ"도 같은 칸 모양. 색은 아주 연한 보라(`--brand-faint` #f7f4ff), 예약 묶음은 아주 연한 주황(`--reserve-faint` #fff9ef). PC에서 모든 카드 높이가 같음.
- **도서관 이름 옆 "구독형" 표시 없앰**(오른쪽 상태가 이미 "구독형"이라서). 이제 결과 줄에서 `platformType`을 쓰는 곳이 없음.
- 폰 카드: 책 제목·저자 → 가는 선 → 도서관 이름 → (상태 칸이 있으면 그 오른쪽에) 보유 칸. 실제 폭 약 360px부터 한 줄.

### 1-5. 정렬

사진: `pc-sort-list-with-help.png`

- 정렬 상자 옆 "?" 버튼 없앰. **정렬 상자를 누르면 열리는 목록 안**에 세 순서, 가는 선, "? 정렬 기준 보기". 그 줄을 누르면 목록이 닫히지 않고 아래에 "기본 순서" 설명이 펼쳐짐.
- 부품을 Radix Select에서 DropdownMenu(라디오 항목)로 바꿈(키보드로 "?" 줄에 가려고). 상자 읽는 이름 "정렬: {지금 순서}".
- 폰에서는 이 상자가 검색줄 둘째 줄 오른쪽 끝에 있음(1-3). "도서관에서 직접 찾기"일 때 폰에서는 흐린 정렬과 이유 글을 보이지 않음.

### 1-6. 그 밖

- 안내 줄(머리말 아래 "가입했어요" 등)은 다른 페이지로 가면 사라짐(사이클 06 마무리 때 이미 알림, AC-17).
- 새 색·폭 토큰(`web/src/styles/global.css`): `--brand-faint`, `--reserve-faint`, `--tray`, `--content-width`. `--brand-mist`(로그인 뒤 "내 도서관" 상자 색)는 그 상자가 없어져 지금은 쓰지 않음.

## 3. plan이 정할 것 [확인 필요]

1. **폰 S1 설정 창의 모양**: 지금은 설정 버튼 아래의 작은 창 그대로입니다. 사용자가 고른 D안 시안은 "아래에서 올라오는 창"(토스 앱 방식)이었습니다. 바꿀지는 정하지 않았습니다.
2. **폰에서 "도서관에서 직접 찾기"일 때의 정렬 안내**: 흐린 정렬과 "정렬은 쓸 수 없어요" 글을 폰에서는 보이지 않습니다(정렬 자리가 검색줄로 옮겨 가서). 안내가 필요하면 위치를 정해야 합니다.
3. **"대출 중 · 예약" 등 남은 상태 칸의 색**: 보유 칸은 연보라로 바꿨고, 남은 상태 칸은 전의 색(연보라·연주황) 그대로입니다. 맞출지는 정하지 않았습니다.
4. **카드 전체 링크와 글자 선택**: 카드 전체가 링크라 카드 안 글자(책 제목 등)를 끌어서 고르기가 어렵습니다. 문제가 되면 방법을 정해야 합니다.
5. 앞서 넘긴 것(그대로): 글꼴 파일 크기(나눔바른고딕 약 3MB) 서브셋 여부, S8·S9에서 돌아오는 길.
