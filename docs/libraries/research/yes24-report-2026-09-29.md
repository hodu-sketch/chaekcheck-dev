## 사람이 정할 것

1. **EUCKR_V2 4곳**(마포나루, 김천, 경주, 구미): 새 adapter 변형이 필요. 이름을 `YES24_V3`로 할지, V2에 charset만 바꿀지.
2. **같은 도서관의 두 번째 사이트 이름**: 26곳은 같은 기관의 교보(또는 포털·구독) 줄이 이미 seed에 있음. 예: 후보 이름 "고양시도서관센터" vs seed "고양시 도서관센터", "용인시도서관" vs "용인시립도서관". name UNIQUE와 화면 구분을 위해 "(YES24)" 같은 꼬리표를 붙일지.
3. **판단 보류 가입 자격**: 경산(규정 ③ "온라인 회원 가입으로 도서대출회원증을 발급 받은 것으로 본다" → REGION 유지냐 OPEN_CAUTION이냐), 영천(근거가 게시판 답변뿐), 광주남구·광주시립·광주장덕(대출회원 발급에 지역 문구 없음, "제한 없음"도 없음 → UNVERIFIED로 둠), 금산(OPEN으로 봤으나 "거주지 확인" 제목 있음), 은평(OPEN, 방문 필요 여부).
4. **공공도서관이 맞는지**: 북나들e전자도서관(대전육아종합지원센터 서비스), 대구점자도서관(시각장애인 대상), 국립세종도서관(국가 도서관, 방문 대출증 필요).
5. **보유 수 NULL 3곳**(춘천·국립세종·경산): 빈 검색이 5초 넘음. NULL로 둘지(그룹 맨 뒤), 더 긴 제한으로 한 번 잴지.
6. **전남교육청 YES24 8곳**: 사이트마다 보유가 69\~6,922권. 한 기관의 분관 사이트라 모두 넣을지, 통합(8891)만 넣을지. 자격은 원문 못 찾아 UNVERIFIED.
7. **옛 주소라 새 주소를 찾아야 하는 곳**: 포항·통영·양산·밀양·경남대표(`/YES24` 오류 화면), 울산(404 페이지로 이동), 강원교육청(`ebook.gwe.go.kr` 다른 화면), 성동영어·충남도서관(400), 사상(500) 등 — 위 표.
8. robots.txt: 이번에는 따로 읽지 않음(검색 1건만). plan 조사에서 YES24 새 화면 표본은 모두 `Disallow: /`였고, 사용자 결정대로 후보로 둠.

## 파일

- `yes24-candidates.tsv` 도구 입력(110곳), `yes24-skipped.tsv` 뺀 18곳
- `yes24-search.tsv`, `yes24-holdings.tsv` 도구 출력(보유는 OK+NO_ADAPTER 66곳만 잼)
