# AI 책 찾기 — 한 장 요약

- **이 문서가 답하는 것**: 책첵 「AI 책 찾기」가 무엇이고, 어떻게 동작하고, 어떻게 재서 무엇을 고쳤나. 처음 보는 사람을 위한 한 장입니다.
- **더 자세히**: 모든 전후 숫자와 버린 안 → [4-results.md](4-results.md), 지금 동작의 표·계산 → [1-how-it-works.md](1-how-it-works.md), 버전별 변화 → [2-versions.md](2-versions.md), 쓴 ML 모델 → [3-ml-models.md](3-ml-models.md).

## 한 줄로

「번아웃이 왔을 때 읽을 책」, 「아몬드 같은 성장 소설」처럼 **말로 물으면**, 전자책 약 7만 7천 권 중에서 맞는 책을 골라 카드로 보여 주고, 이어서 「더 쉬운 거」, 「그중에 소설만」처럼 대화하듯 좁혀 갈 수 있는 기능입니다(주소 `/ai-search`).

## 어떻게 동작하나

1. **질문 해석**: 질문을 한국어 문장 임베딩 모델(KURE-v1)로 숫자 1,024개짜리 벡터로 바꾸고, 그 위의 작은 신경망(MLP)이 「책 찾기인지 잡담인지」, 어떤 분야·대상·형식인지, 앞 질문과 어떤 관계인지(이어서 좁히기·주제 바꾸기 등)를 정합니다. 처음에는 이 단계도 AI(Claude Haiku) 호출이었는데, 품질은 그대로 두고 더 빠르고 싸게 하려고 학습한 모델로 바꿨습니다.
2. **후보 찾기**: 두 가지 방법으로 책을 찾아 하나의 순위로 합칩니다.
   - 낱말 검색: 질문의 낱말이 책 요약과 핵심 낱말에 얼마나 맞는지(PostgreSQL 위의 BM25 한국어 전문 검색).
   - 뜻 검색: 질문 벡터와 책 벡터가 얼마나 가까운지. 책 벡터는 책 요약과, 책 소개를 512토큰씩 나눈 조각에서 만듭니다.
   - 두 순위를 RRF(순위 역수 더하기)로 합쳐 앞 30권을 후보로 둡니다.
3. **고르기와 설명**: 후보 30권의 제목·저자·출간 연도·요약을 Claude Haiku에 보내면, 질문에 맞는 책을 최대 8권 골라 왜 맞는지 한 줄씩 씁니다. 답은 만들어지는 대로 화면에 흘려 보내(SSE) 첫 글이 2초 안팎에 보입니다.
4. **되묻기**: 「파이썬」처럼 뜻이 여럿인 질문에는 책 대신 「어떤 쪽을 찾으세요?」와 고를 답을 보여 줍니다.

## 어떻게 쟀나

정답 책이 정해진 질문(예: 소개 뒷부분 내용으로 묻는 질문 750개)과 주제 질문을 만들어, 같은 질문 묶음을 고치기 전과 후에 돌립니다. 카드마다 Claude Sonnet이 「질문에 맞나」를 0\~3점으로 채점합니다. 같은 입력을 두 번 돌려도 몇 %p 흔들리므로, 그보다 작은 차이는 차이로 보지 않고, 중요한 비교는 두 번씩 돌려 평균을 냅니다.

## 무엇을 고쳤나 (주요한 것)

| 고친 것 | 전 → 후 |
|---|---|
| 낱말 검색만 쓰던 것에 뜻 검색과 AI 고르기를 더함 | 딱 맞는 카드 **40 → 74%**, 틀린 카드 **질문당 2.04 → 0.34장** |
| 질문 해석을 AI 호출에서 학습한 작은 모델로 | 카드 품질 그대로, 느린 10% **11.4 → 9.7초**, 검색 1,000번 비용 **$1.52 → $1.40** |
| 애매한 질문에 되묻기 + AI 응답 방식 조정 | 애매한 질문 맞음 **66.7 → 78.8%**, 첫 글 **4.0 → 2.3초** |
| 책 소개 전체를 조각으로 나눠 벡터로 + BM25 낱말 검색 (v1.23.0) | 찾는 책이 카드에 나옴 **40.3 → 60.1%**, 1번 카드로 나옴 **29.5 → 42.3%** |
| 오래 켜진 서버에서 낱말 검색이 느려지던 DB 실행 계획 문제 | **5.17 → 0.24초** ([책 설명 모으기 요약 1절](../book-descriptions/1-summary.md)) |

## 재 보고 넣지 않은 것

숫자로 확인하고 넣지 않은 안도 많습니다. 예를 들어 AI가 스스로 다시 찾고 되묻는 「에이전트」 방식은 정확도가 흔들림 안에서 같았지만 첫 글이 두 배 늦고 비용이 3분의 1 넘게 늘어, 되묻기만 떼어 넣었습니다. 후보를 50권으로 늘리기, AI가 지어낸 「가상 소개」로 찾기(HyDE) 등도 재 보고 버렸습니다. 전체 목록: [4-results.md 3절](4-results.md#3-재-보고-버린-것), [2-versions.md](2-versions.md#재-보고-내지-않은-것).
