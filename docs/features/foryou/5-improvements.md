## 2. 안별 내용

### I-01 문턱 3 — 운영 v1.20.2 (2026-10-29)
- 문제: O2(유사도 순)로 바꾼 뒤 내 도서관 1곳만 가진 책이 추천 20권의 10.7%(가입 가능 범위) → 빌리러 가면 대출 중일 수 있음
- 바꿀 곳: `ForYouController.similarBooks`의 `cards()` 뒤. 책마다 `planLibraryCount = |catalog.book.library_ids ∩ planIds|`, `instant = (catalog.book.library_ids ∩ planIds)` 안에 `library.library.lending_model IN ('SUBSCRIPTION','RENTAL')`인 도서관이 있음. **통과 = instant 또는 planLibraryCount ≥ 3**. 통과한 책을 지금 차례대로 앞에, 못 넘은 책은 통과한 책이 60권에 못 미칠 때만 그 뒤에
- 근거: E7 — 바로 대출 48 → 61%, 1곳뿐 11% → 0%, 판정 3.78 → 3.86(손해 없음). 기본 범위(377곳)는 거의 그대로
- 구현: `SimilarOrder.availableFirst`(상수 `MIN_PLAN_LIBRARIES = 3`), `ForYouController.availableFirst`(계획 `SearchTarget.lendingModel`로 바로 대출 도서관을 고르고 `BookCards.cards`의 `libraryIds`로 셈). 시험 `SimilarOrderTests.picksHeldByThreePlanLibrariesOrAnInstantOneComeFirstInTheirOrder`. 백엔드 `./gradlew build`, 웹 빌드·vitest 709 통과
- 배포: 사용자 "운영에 배포해"(다른 세션 24·26·27에 차례를 물어 모두 「먼저 올려도 됨」 뒤), v1.20.2 백엔드만, 커밋 180897a1
- 운영 측정(v1.20.2, 2026-10-29): 책 1172·10을 기준으로 16개 시·도(각 첫 시·군·구, `scope=joinable`)에 물었더니, 모두 앞 27\~34권이 통과한 책이고 그 뒤 1\~2곳 책(4\~8권)이 붙음. 기본 범위(377곳)에서는 20·40권 모두 통과해 순서가 O2와 같음
- 결정: 사용자 2026-10-29 "문턱 3으로". 설계 AC-5(「계획 도서관 1곳 이상」)보다 좁힘 → plan에 알림

### I-02 카드에 「바로 대출」 표시 — 제안
- 카드 응답에 `instant`(I-01과 같은 계산) 칸을 더하고 표지 위에 작은 표시. 순서는 바꾸지 않음
- 근거: 가중치로 순서를 바꾸면 판정 −5.6%p(E6), 표시는 순서를 안 바꿈
- 화면이 바뀌므로 시안 먼저

### I-03 교보 「대여」가 바로 대출인지 — 확인 필요
- `library.library.lending_model`의 `RENTAL`은 교보 기관 사이트 첫 화면의 `library_model: '대여'`(`docs/libraries/library-maintenance.md` 4절). 서울도서관 구독형은 이용 안내 원문 "구독형 : 15,000여 종(대출 수 제한 없음)"으로 확인됨. 교보 「대여」의 동시 대출 제한은 기록 없음
- 방법: 교보 이용 안내 원문을 찾아 `docs/libraries/library-maintenance.md`에 기록(도서관 조사 규칙). `*.dkyobobook.co.kr`에는 요청하지 않는 규칙이 있어 다른 출처로

### I-09 판단 모델(Jev)로 요청마다 다시 줄 세우기 — 제안

## 3. 사이클 26과의 관계
사이클 26(dev 26 세션)이 `foryou.book_blurb`·`book_cover`·`picks.book_tag`·`tag_dictionary`·`picks/ai-summaries.tsv`·AI 검색 프로필 파일을 `catalog`로 옮기고 책첵 추천의 읽는 곳도 고침(plan `docs/cycles/26-book-descriptions/to-dev23-24.md` 3절). 그래서 I-01·I-02·I-04·I-07·I-10\~I-14는 26 배포 뒤 main 위에서 함.
